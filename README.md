# 政策シミュレーションゲーム(Ollamaプロトタイプ)

`設計資料/` の構想(バブル期モード・現代モード、50社会指標、AIによる政策影響評価・
史実イベント判定)のうち、**Ollamaで動くローカルLLMの挙動を試すための最小プロトタイプ**。

## できること

- モード選択: バブル期モード(1988年開始) / 現代モード(2000年開始)、各30年間
- 開始時に約50個の社会指標(GDP・出生率・国民満足度・健康寿命など)を表示
- 自由記述の政策を入力 → Ollamaモデルに問い合わせて「良い影響3つ・悪い影響3つ」を
  JSON Schemaに従って取得し、ガウス型のインパルスとして各指標に反映
- 台本化された史実イベント(諸外国の出来事・自然災害)を年ごとに発生させ、
  諸外国の出来事は「史実通り発生するか / 影響度1〜5」をAIに判定させる。
  自然災害は史実通り必ず発生し、耐災害指数で被害を軽減する
- 30年経過 or 指標が破綻ラインを割る/超える → ゲームオーバー、
  目標水準を全て満たす → クリア
- 直近のAI応答(生JSON・応答時間)を画面に表示するので、モデルごとの
  出力傾向やスキーマ遵守率・速度を比較しやすい

## セットアップ

### 1. Ollama本体のインストール

公式サイト https://ollama.com/download からインストーラーを取得するか、
WSL/Linuxなら以下でインストールしてください(このコマンド自体は各自の環境で実行してください)。

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. Ollamaサーバー起動 & モデル取得

```bash
ollama serve
```

別ターミナルで、比較したいモデルをpull(タグ名は `ollama.com/library` で確認してください。
設計資料にある「Qwen3.8-27B」「Gemma4」「Llama4 Scout」はモデル名の表記ゆれがあるため、
実際に配布されているタグ名に読み替えてください):

```bash
ollama pull qwen2.5:14b
ollama pull gemma3:12b
ollama pull llama4:scout
```

### 3. Python環境

```bash
pip install -r requirements.txt
```

### 4. 起動

```bash
streamlit run app.py
```

## ディレクトリ構成

```
app.py                 Streamlit UI
game/
  indicators.py        50社会指標の定義、モード別初期値・勝敗条件
  events.py            史実イベント(諸外国の出来事・自然災害)の台本データ
  prompts.py           Ollamaへ渡すプロンプトとJSON Schema
  ollama_client.py      Ollama呼び出しラッパー(構造化出力・所要時間計測)
  simulation.py         年次進行ロジック(効果の重ね合わせ・勝敗判定)
```

## 既知の制約(プロトタイプゆえの簡略化)

- 史実イベントは各モード5件のみ台本化(サンプル)。増やす場合は `game/events.py` に追記
- 政策効果の「大きさ」はAIには出力させず、指標ごとに固定の基準量(`impact_unit`)を
  ガウス関数でスケールする方式(設計資料のJSON Schemaに数値の大きさフィールドが
  無いための割り切り)
- 指標の初期値・勝敗条件のしきい値は仮置きの値。バランス調整は別途必要
- クラウドLLMへのフォールバックは未実装(Ollamaのみ)
